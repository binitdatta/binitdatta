CAREER JOURNEY

Three decades of enterprise technology—without standing still.

My career has moved across industries, architectures and technology generations while staying grounded in one discipline: solving real business problems with production-ready engineering.

1990s

Business-first ERP foundations

Led and built company-wide ERP solutions requiring direct study of finance, accounting, inventory, purchasing, payroll, sales, operations and industry-specific workflows. Early work included Oracle database and Developer 2000-based enterprise systems.

Oracle • ERP • Relational Data Modeling • Forms & Reports • Business Process Analysis
2000s

Distributed enterprise systems

Expanded into Java and distributed enterprise platforms across telecom, mortgage, healthcare and other domains, deepening architecture, integration and large-system problem solving.

Java • Enterprise Integration • Distributed Systems • Web Applications • APIs
2010s

Digital, retail and cloud modernization

Worked across high-volume retail, eCommerce and enterprise modernization, including microservices, cloud platforms, performance, DevOps and large distributed application ecosystems.

Microservices • REST • Cloud • eCommerce • DevOps • Observability
2020s

Global SaaS, IAM and platform security

Focused heavily on cloud-native SaaS architecture, identity and access management, multi-tenancy, federation and regulated security patterns using modern Spring Security, Keycloak and major cloud ecosystems.

OAuth2 • OIDC • SAML 2.0 • Keycloak • Entra ID • Kubernetes • FedRAMP
Now

Enterprise AI and agentic systems

Applying GenAI and Agentic AI to enterprise workflows where identity, authorization, data access, transaction integrity, governance, auditability and human accountability matter as much as model capability.

Python • LangChain • LangGraph • RAG • Agents • AI Governance • Secure Tool Calling
